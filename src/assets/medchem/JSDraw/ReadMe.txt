
This folder contains all js files to used by HELM Web Editor:

- Pistoia.HELM.js: Merged HELM Web Editor javascript file, compressed to minimized network traffic.
- Pistoia.HELM-umcompressed.js: Merged HELM Web Editor javascript file.
- sc900807._drawnm2.Lite.js: Merged _drawnm Lite javascript file, compressed to minimized network traffic.  Its source code can be found at: https://github.com/scilligence/_drawnm.Lite
- sc900807._drawnm2.Lite-umcompressed.js:  Merged _drawnm Lite javascript file.
- sc900807._drawnm2.Resources.js: _drawnm resources, used by _drawnm Lite.
